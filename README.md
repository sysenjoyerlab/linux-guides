## English
The goal of this project is to document everything possible about Linux in a wiki format. The difference from other sources is that this repository is intended to help the user truly learn.

I am a student, and the content will evolve from the basics to wherever we go. Any criticism or suggestion is more than welcome.

### 🚀 Goal
Build a solid knowledge base through "active learning." Everything here is based on my own experience and lab work, always seeking to understand the *why* behind every command and configuration.
